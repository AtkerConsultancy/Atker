About the pack

Learn it by doing it

Most people try an AI assistant, get an average answer and give up. The difference is rarely the tool. It is knowing how to ask, how to check the answer and how to build the habit into the working week.

Each module takes about 45 minutes: a short read, a hands-on task using the practice files, and a three-minute reflection. By the end you will have a set of prompts, templates and checks that you actually use, plus a capstone workflow of your own.

Read it, try it, check it, keep what works.

How it works

Four steps

Set up

Open the handbook, create your account and take the baseline so you can see your own progress.

Work a module

Read for about 25 minutes, then practise for about 20 using the files provided.

Check and reflect

Verify what Claude produced and note what worked. Good habits matter more than clever prompts.

Build your workflow

Finish with a capstone workflow you can use at work the next day.
